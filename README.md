# 生字語詞練習

115 學年度南一國語**三年級上學期**生字語詞小遊戲。第一課〈你好，新朋友〉可以玩，其他課之後會一課一課加上去。

玩法對齊 UDL 課堂教材的識字練習：大字、直式注音、可以聽、配對、小考。錯了不扣分羞辱，再試一次就好。

## 直接玩

網址（啟用 GitHub Pages 後）：

https://cyclone-tw.github.io/udl-vocab-play/

教師列印頁：同一個網站打開後點「列印 QR」，用手機相機掃。

本站只放生字與語詞練習，**不放課文**。

## 第一課內容

- 課名：你好，新朋友（翁士行）
- 習寫生字 15 個：泥、化、雀、輕、羽、衣、脆、髮、處、旅、行、平、男、朗、足
- 語詞 13 個：泥土、化成、小雲雀、輕快、羽衣、清脆、頭髮、四處、旅行、平安、男孩、開朗、足球
